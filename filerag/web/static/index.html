API

GET /healthStatus, version, model, catalog size
GET /filesFind files: name, ext, category, folder, root, min_size, max_size, after, before, sort, order, limit, offset — fast, no LLM
GET /files/{ref}One file: path, size, dates, content status; /text reads its text, /raw downloads it
GET /search?q=…Content search inside files (hybrid keyword + semantic), same filters plus mode
GET /stats?by=extCounts and sizes by ext, category, folder, root, year, month
GET /duplicatesSets of identical files (same filters), sort = wasted, copies or size
GET /folders?path=…Sub-folders with their total size and file count; GET /cleanup lists space that could be freed
GET /rootsMapped folders. POST /roots {"path"} maps a new one (scanned in the background)
POST /askAsk the agent: {"question", "save", "chat_id", "stream"}. save:true stores the chat and returns chat_id for follow-ups; stream:true returns live events
